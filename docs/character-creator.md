# Create a Hunter

A missing character save opens the creator before entering the lobby. Choose a
name, head style (helmet, cropped hair or spiky hair), body preset, armor color,
photon accent, skin tone and hair color. Click the name box to type; Backspace
removes a character. Names allow 1–20 ASCII letters/numbers, spaces, hyphens and
apostrophes. Rotate the live preview with Left/Right or middle mouse drag.
Click **Begin adventure** or press Enter to confirm. Escape or closing the
window cancels without creating a save.

These original, stylized presets are cosmetic. Body proportions never change
collision, reach, health or damage. The preview, game and visual editor use the
same Hunter mesh and rig. Future imported bodies can replace this initial art.

Confirmation saves the character's identity and appearance. Existing version 1
profiles load as the original helmeted Hunter while preserving all progression,
gear and money; they do not enter the creator. New writes use version 2 and keep
the previous valid file as a backup. Invalid or newer saves are preserved and
never treated as a blank character. See [saving](saving.md).
