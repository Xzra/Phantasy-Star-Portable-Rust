Start with one small change

  1. Extract the entire engine ZIP into a folder you can edit. Keep the files together.
  2. Double-click Start-Editor.cmd. The starter project opens in the visual editor.
  3. Choose Gameplay → Movement and raise Walk speed a little. Keep Sprint speed at least as high.
  4. Click Save, then Play / F6. The game opens using that exact project.
  5. Close the game to return to the editor. Try a character color, a different animation, or a new scene prop next.

Editor playtests never read or write your character save. To play your saved character normally, open phantasy-star.exe. A new save begins with character creation.

What each tab does

Character

Choose the default name, head style, body preset and armor, accent, skin and hair colors. The live model uses the same rig as the game.

Defaults affect new saves and playtests; existing characters keep their appearance.

Animation

Select a weapon mesh and clip, pause and scrub the timeline, show bones, or slow playback. Animation energy changes the strength of the attack poses.

Playback speed is for preview. Gameplay attack-speed settings change actual combat.

Gameplay

Tune walk/sprint speed, jump, gravity, enemy approach speed and damage, PP recovery, and each weapon class’s damage, reach and attack speed.

Scene

Add solid colored props to the lobby or field. Edit position, width, height, depth and color. Yellow outlines select props; cyan circles mark protected interactions.

Invalid placements remain editable but cannot be saved or played.

Make your own project

Copy projects/starter to a new folder. Drag the copied project.json onto Start-Editor.cmd. The editor shows its current file at the bottom. Keep your project folder and use the same engine version when sharing it.

Project files contain design data. Player profiles contain character identity, progression, money and equipment. They are separate files with separate backup and validation rules.

When you want to change the code

The engine kit includes the full release source under source/. Install Rust and follow its Windows C++ build prerequisites. Then open source/Build-Engine.cmd. The first build needs internet access for dependencies; running the editor does not require Rust.

cargo run --locked --features viewer --bin engine-editor
cargo run --locked --features viewer --bin phantasy-star

Run commands from the source folder containing Cargo.toml. The build launcher opens the source project’s editor, so your rebuilt game and editor stay together.

What this first editor supports

This is a focused engine workbench for the current solo game: appearance presets, shared animation preview and energy adjustment, balance settings, solid prop placement and playtesting. New weapon classes, detailed pose curves, custom gameplay, quests, meshes and terrain still require Rust changes.

General scene graphs, arbitrary imported-model placement, scripting, skeletal curve editing, terrain sculpting and a standalone-game export wizard are future work. The source is included so you can extend the engine yourself.

Original character, weapons and scenery. No proprietary game assets are bundled. Keep THIRD_PARTY_NOTICES.md and the font license when sharing builds.
