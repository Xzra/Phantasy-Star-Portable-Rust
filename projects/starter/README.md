# Starter project

Open `project.json` with `Start-Editor.cmd` in the Windows engine package.
The default document reproduces the standard game's balance and has no extra
props. Save changes in the editor and press F6 for an isolated playtest.

To make another project, copy this folder, give it a new name, and drag the copied
`project.json` onto `Start-Editor.cmd`. A project file is game design data; it is
separate from a player's character save. See `docs/engine-guide.md`.
